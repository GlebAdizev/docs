Урок 2: переменные, типы данных, константы

В этом уроке мы познакомимся с переменными, основными типами данных и константами в C++.

Переменные

Переменная — это именованная область памяти, в которой хранится значение. Перед использованием переменную нужно объявить, указав её тип:

    int age = 25;
    double price = 99.99;
    char letter = 'A';
    bool isTrue = true;

Основные типы данных

  • int — целые числа (например, 10, -5, 0).
  • double — числа с плавающей точкой (например, 3.14, -0.5).
  • char — один символ (например, 'A', 'z', '7').
  • bool — логический тип (true или false).
  • string — строка символов (нужно подключить <string>).

Константы

Константа — это значение, которое нельзя изменить после объявления. В C++ константы объявляются с помощью ключевого слова const:

    const double PI = 3.14159;
    const int DAYS_IN_WEEK = 7;

Попытка изменить константу вызовет ошибку компиляции.

Пример программы

    #include <iostream>
    #include <string>
    
    int main() {
        int age = 25;
        std::string name = "Иван";
        const double PI = 3.14159;
        
        std::cout << "Имя: " << name << std::endl;
        std::cout << "Возраст: " << age << std::endl;
        std::cout << "Число PI: " << PI << std::endl;
        
        return 0;
    }
