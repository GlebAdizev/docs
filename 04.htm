Урок 4: ветвления (if, switch)

В этом уроке мы научимся управлять ходом выполнения программы с помощью условных операторов if и switch.

Оператор if

Простейшая форма ветвления — это оператор if. Если условие истинно, выполняется блок кода:

if (условие) {
    // код, который выполнится, если условие истинно
}

Пример:

int age = 18;

if (age >= 18) {
    std::cout << "Доступ разрешён" << std::endl;
}

Конструкция if-else

Если нужно выполнить один блок кода при истинном условии и другой — при ложном, используется else:

if (условие) {
    // код, если условие истинно
} else {
    // код, если условие ложно
}

Пример:

int age = 16;

if (age >= 18) {
    std::cout << "Доступ разрешён" << std::endl;
} else {
    std::cout << "Доступ запрещён" << std::endl;
}

Конструкция else if

Для проверки нескольких условий используется цепочка else if:

int score = 85;

if (score >= 90) {
    std::cout << "Отлично" << std::endl;
} else if (score >= 75) {
    std::cout << "Хорошо" << std::endl;
} else if (score >= 60) {
    std::cout << "Удовлетворительно" << std::endl;
} else {
    std::cout << "Неудовлетворительно" << std::endl;
}

Оператор switch

Оператор switch удобен, когда нужно сравнить одну переменную с несколькими значениями:

int day = 3;

switch (day) {
    case 1:
        std::cout << "Понедельник" << std::endl;
        break;
    case 2:
        std::cout << "Вторник" << std::endl;
        break;
    case 3:
        std::cout << "Среда" << std::endl;
        break;
    default:
        std::cout << "Другой день" << std::endl;
}

Оператор break завершает выполнение switch. Без него выполнение «провалится» в следующий case.

Пример программы

#include <iostream>

int main() {
    int age = 20;
    
    if (age >= 18) {
        std::cout << "Вы совершеннолетний" << std::endl;
    } else {
        std::cout << "Вы ещё несовершеннолетний" << std::endl;
    }
    
    int day = 5;
    switch (day) {
        case 5:
            std::cout << "Пятница!" << std::endl;
            break;
        default:
            std::cout << "Не пятница" << std::endl;
    }
    
    return 0;
}
