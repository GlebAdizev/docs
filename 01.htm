Урок 1: первая программа, компиляция

В этом уроке мы напишем первую программу на C++ и научимся её компилировать.

Первая программа

Традиционно первая программа выводит на экран приветствие. Вот её код:

#include <iostream>

int main() {
    std::cout << "Привет, мир!" << std::endl;
    return 0;
}

Разбор программы

  • #include <iostream> — подключает библиотеку для ввода-вывода.
  • int main() — главная функция, с которой начинается выполнение программы.
  • std::cout — поток вывода на экран.
  • << — оператор передачи данных в поток.
  • return 0; — завершает программу с кодом 0 (успех).

Компиляция

Чтобы запустить программу, её нужно скомпилировать. Например, в компиляторе g++ это делается так:

g++ main.cpp -o main
./main

После выполнения вы увидите на экране:

Привет, мир!
