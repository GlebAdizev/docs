Урок 8: конструкторы и деструкторы

В этом уроке мы изучим специальные методы класса — конструкторы и деструкторы.

Конструктор

Конструктор — это метод, который автоматически вызывается при создании объекта. Его имя совпадает с именем класса, и он не имеет возвращаемого типа.

    class Cat {
    public:
        std::string name;
        
        Cat(std::string n) {
            name = n;
            std::cout << "Создан кот " << name << std::endl;
        }
    };

Создание объекта с конструктором

    Cat cat1("Барсик");   // Создан кот Барсик
    Cat cat2("Мурка");    // Создан кот Мурка

Конструктор по умолчанию

Если конструктор не объявлен, компилятор создаёт его автоматически. Можно также задать значения по умолчанию:

    Cat(std::string n = "Безымянный") {
        name = n;
    }

Деструктор

Деструктор вызывается автоматически при уничтожении объекта. Его имя — это имя класса с символом ~ в начале.

    class Cat {
    public:
        ~Cat() {
            std::cout << "Кот удалён" << std::endl;
        }
    };

Пример программы

    #include <iostream>
    #include <string>
    
    class Cat {
    public:
        std::string name;
        
        Cat(std::string n) {
            name = n;
            std::cout << "Создан кот " << name << std::endl;
        }
        
        ~Cat() {
            std::cout << "Кот " << name << " удалён" << std::endl;
        }
    };
    
    int main() {
        Cat cat1("Барсик");
        Cat cat2("Мурка");
        
        return 0;  // здесь вызываются деструкторы
    }
