Урок 9: наследование

В этом уроке мы изучим наследование — механизм, позволяющий создавать новый класс на основе существующего.

Что такое наследование?

Наследование позволяет новому классу (наследнику) перенимать поля и методы родительского класса (базового). Это уменьшает дублирование кода и упрощает его поддержку.

Синтаксис наследования

    class Базовый {
        // поля и методы
    };
    
    class Наследник : public Базовый {
        // дополнительные поля и методы
    };

Пример

    class Animal {
    public:
        void eat() {
            std::cout << "Животное ест" << std::endl;
        }
    };
    
    class Cat : public Animal {
    public:
        void meow() {
            std::cout << "Мяу!" << std::endl;
        }
    };

Класс Cat наследует метод eat() от класса Animal и добавляет свой метод meow():

    Cat cat;
    cat.eat();   // Животное ест
    cat.meow();  // Мяу!

Типы наследования

  • public — открытое наследование (наиболее частое).
  • protected — защищённое наследование.
  • private — закрытое наследование.

Переопределение методов

Наследник может переопределить метод базового класса:

    class Cat : public Animal {
    public:
        void eat() {
            std::cout << "Кот ест рыбу" << std::endl;
        }
    };

Пример программы

    #include <iostream>
    
    class Animal {
    public:
        void eat() {
            std::cout << "Животное ест" << std::endl;
        }
    };
    
    class Cat : public Animal {
    public:
        void meow() {
            std::cout << "Мяу!" << std::endl;
        }
    };
    
    int main() {
        Cat cat;
        cat.eat();
        cat.meow();
        
        return 0;
    }
