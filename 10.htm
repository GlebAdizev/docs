Урок 10: полиморфизм, виртуальные функции

В этом уроке мы изучим полиморфизм — одну из ключевых концепций ООП, и разберём виртуальные функции.

Что такое полиморфизм?

Полиморфизм позволяет работать с объектами разных классов через единый интерфейс базового класса. Один и тот же вызов метода может приводить к разному поведению в зависимости от типа объекта.

Виртуальные функции

Чтобы метод мог быть переопределён в наследниках и вызывался динамически, его объявляют с ключевым словом virtual:

    class Animal {
    public:
        virtual void sound() {
            std::cout << "Какое-то животное издаёт звук" << std::endl;
        }
    };

Переопределение в наследниках

    class Cat : public Animal {
    public:
        void sound() override {
            std::cout << "Мяу!" << std::endl;
        }
    };
    
    class Dog : public Animal {
    public:
        void sound() override {
            std::cout << "Гав!" << std::endl;
        }
    };

Полиморфный вызов

Через указатель или ссылку на базовый класс можно вызывать методы наследников:

    Animal* a1 = new Cat();
    Animal* a2 = new Dog();
    
    a1->sound();  // Мяу!
    a2->sound();  // Гав!

Чисто виртуальные функции

Если у метода нет реализации в базовом классе, его делают чисто виртуальным (= 0). Класс с такими методами называется абстрактным — от него нельзя создать объект.

    class Animal {
    public:
        virtual void sound() = 0;  // чисто виртуальная
    };

Виртуальный деструктор

Если класс используется полиморфно, деструктор тоже стоит делать виртуальным:

    class Animal {
    public:
        virtual ~Animal() {}
    };

Пример программы

    #include <iostream>
    
    class Animal {
    public:
        virtual void sound() {
            std::cout << "Звук животного" << std::endl;
        }
        virtual ~Animal() {}
    };
    
    class Cat : public Animal {
    public:
        void sound() override {
            std::cout << "Мяу!" << std::endl;
        }
    };
    
    class Dog : public Animal {
    public:
        void sound() override {
            std::cout << "Гав!" << std::endl;
        }
    };
    
    int main() {
        Animal* animals[2];
        animals[0] = new Cat();
        animals[1] = new Dog();
        
        for (int i = 0; i < 2; i++) {
            animals[i]->sound();
        }
        
        delete animals[0];
        delete animals[1];
        
        return 0;
    }
