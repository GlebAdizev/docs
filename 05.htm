Урок 5: циклы (for, while, do-while)

В этом уроке мы изучим циклы — конструкции, которые позволяют повторять выполнение блока кода несколько раз.

Цикл for

Цикл for используется, когда заранее известно количество повторений. Он состоит из трёх частей: инициализация, условие и шаг.

    for (инициализация; условие; шаг) {
        // тело цикла
    }

Пример — вывод чисел от 1 до 5:

    for (int i = 1; i <= 5; i++) {
        std::cout << i << std::endl;
    }

Цикл while

Цикл while выполняется, пока условие истинно. Проверка условия происходит перед каждой итерацией:

    while (условие) {
        // тело цикла
    }

Пример:

    int i = 1;
    
    while (i <= 5) {
        std::cout << i << std::endl;
        i++;
    }

Цикл do-while

Цикл do-while похож на while, но проверка условия происходит после выполнения тела. Это значит, что тело цикла выполнится хотя бы один раз:

    do {
        // тело цикла
    } while (условие);

Пример:

    int i = 1;
    
    do {
        std::cout << i << std::endl;
        i++;
    } while (i <= 5);

Операторы break и continue

  • break — немедленно прерывает выполнение цикла.
  • continue — пропускает оставшуюся часть тела цикла и переходит к следующей итерации.

Пример с break:

    for (int i = 1; i <= 10; i++) {
        if (i == 5) break;
        std::cout << i << std::endl;
    }

Пример с continue:

    for (int i = 1; i <= 5; i++) {
        if (i == 3) continue;
        std::cout << i << std::endl;
    }

Пример программы

    #include <iostream>
    
    int main() {
        // Цикл for
        std::cout << "Цикл for:" << std::endl;
        for (int i = 1; i <= 5; i++) {
            std::cout << i << " ";
        }
        std::cout << std::endl;
        
        // Цикл while
        std::cout << "Цикл while:" << std::endl;
        int j = 1;
        while (j <= 5) {
            std::cout << j << " ";
            j++;
        }
        std::cout << std::endl;
        
        // Цикл do-while
        std::cout << "Цикл do-while:" << std::endl;
        int k = 1;
        do {
            std::cout << k << " ";
            k++;
        } while (k <= 5);
        std::cout << std::endl;
        
        return 0;
    }
