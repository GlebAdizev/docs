Урок 6: функции и области видимости

В этом уроке мы научимся создавать собственные функции и разберёмся с областями видимости переменных.

Что такое функция?

Функция — это именованный блок кода, который можно вызывать многократно. Функции помогают избежать дублирования кода и делают программу более структурированной.

Объявление и определение функции

Функция состоит из возвращаемого типа, имени, списка параметров и тела:

    тип_возврата имя_функции(параметры) {
        // тело функции
        return значение;
    }

Пример простой функции, которая складывает два числа:

    int sum(int a, int b) {
        return a + b;
    }

Вызов функции

Чтобы использовать функцию, её нужно вызвать по имени, передав нужные аргументы:

    int result = sum(3, 5);
    std::cout << result << std::endl;  // 8

Функция void

Если функция не возвращает значение, используется тип void:

    void greet() {
        std::cout << "Привет!" << std::endl;
    }
    
    greet();  // вызов функции

Параметры по умолчанию

В C++ можно задавать значения параметров по умолчанию:

    int multiply(int a, int b = 2) {
        return a * b;
    }
    
    std::cout << multiply(5);     // 10
    std::cout << multiply(5, 3);  // 15

Области видимости

Переменные, объявленные внутри функции, называются локальными — они видны только внутри этой функции. Переменные, объявленные вне всех функций, называются глобальными — они видны во всей программе.

    int globalVar = 100;  // глобальная переменная
    
    void show() {
        int localVar = 5;  // локальная переменная
        std::cout << globalVar << std::endl;  // можно
        std::cout << localVar << std::endl;   // можно
    }
    
    // std::cout << localVar;  // ошибка: localVar здесь не видна

Пример программы

    #include <iostream>
    
    int sum(int a, int b) {
        return a + b;
    }
    
    void greet() {
        std::cout << "Привет из функции!" << std::endl;
    }
    
    int main() {
        greet();
        
        int result = sum(3, 5);
        std::cout << "Сумма: " << result << std::endl;
        
        return 0;
    }
