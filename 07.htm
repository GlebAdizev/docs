Урок 7: классы и объекты

В этом уроке мы познакомимся с основами объектно-ориентированного программирования: классами и объектами.

Что такое класс?

Класс — это шаблон, описывающий свойства (поля) и поведение (методы) будущих объектов. Объект — это конкретный экземпляр класса.

Объявление класса

class Cat {
public:
    std::string name;
    int age;
    
    void meow() {
        std::cout << name << " говорит: Мяу!" << std::endl;
    }
};

Создание объекта

Объект создаётся так же, как обычная переменная:

Cat myCat;
myCat.name = "Барсик";
myCat.age = 3;
myCat.meow();  // Барсик говорит: Мяу!

Модификаторы доступа

  • public — доступно всем.
  • private — доступно только внутри класса.
  • protected — доступно классу и его наследникам.

Инкапсуляция

Поля обычно делают приватными, а доступ к ним организуют через методы:

class Cat {
private:
    int age;
public:
    void setAge(int a) {
        if (a >= 0) age = a;
    }
    int getAge() { return age; }
};

Пример программы

#include <iostream>
#include <string>

class Cat {
public:
    std::string name;
    int age;
    
    void meow() {
        std::cout << name << " (" << age << " лет) мяукает!" << std::endl;
    }
};

int main() {
    Cat cat1;
    cat1.name = "Барсик";
    cat1.age = 3;
    cat1.meow();
    
    return 0;
}
