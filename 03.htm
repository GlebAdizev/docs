Урок 3: операторы, выражения

В этом уроке мы изучим основные операторы языка C++ и научимся составлять выражения.

Арифметические операторы

  • + — сложение
  • - — вычитание
  • * — умножение
  • / — деление
  • % — остаток от деления 
    int a = 10, b = 3;
    int sum = a + b;      // 13
    int diff = a - b;     // 7
    int mult = a * b;     // 30
    int div = a / b;      // 3
    int mod = a % b;      // 1

Операторы сравнения

  • == — равно
  • != — не равно
  • > — больше
  • < — меньше
  • >= — больше или равно
  • <= — меньше или равно

Результат сравнения — логическое значение (true или false).

Логические операторы

  • && — логическое И (AND)
  • || — логическое ИЛИ (OR)
  • ! — логическое НЕ (NOT)

Приоритет операторов

Операторы выполняются в определённом порядке. Например, умножение и деление имеют более высокий приоритет, чем сложение и вычитание. Скобки позволяют изменить порядок:

    int result = 2 + 3 * 4;       // 14
    int result2 = (2 + 3) * 4;    // 20

Пример программы

    #include <iostream>
    
    int main() {
        int a = 10, b = 3;
        
        std::cout << "Сумма: " << a + b << std::endl;
        std::cout << "Разность: " << a - b << std::endl;
        std::cout << "Произведение: " << a * b << std::endl;
        std::cout << "Частное: " << a / b << std::endl;
        std::cout << "Остаток: " << a % b << std::endl;
        
        return 0;
    }
